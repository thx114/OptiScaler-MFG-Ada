# Padded DLSS input fix — v0.6.1

Complete OptiScaler package built from runtime commit `bab959eb`. Packaging documentation is updated
for this release. Promoted from preview without changing the binaries. The NR integration remains
experimental; this is not a verified Dawnwalker-specific fix.

## What changed

- NR can stay before DLSS Super Resolution when an origin-zero active image is smaller than its
  colour texture allocation. For example, 2558x1439 inside 2560x1440 no longer automatically sends
  NR to the post-upscale 4K path. This is not a whitelist of specific resolutions.
- Only the active image is copied in/out; padding is preserved. This also handles game colour
  textures without UAV support. Model resolution still follows the active size and `WorkingScale`.
- Includes the earlier per-pass controls, optional skin/environment controls, external FG-owner
  mode and candidate Onimusha state-restoration fix. See the included compatibility documents.
- Includes the pinned Streamline/FG downloader, official sources and installation instructions.
  No NVIDIA NR or FG runtime DLLs, or RTX 40 unlocker binaries, are bundled.

## Update an existing installation

1. Close the game and launcher. Back up the current OptiScaler files and INI.
2. Extract the entire ZIP into a temporary folder first. Follow `INSTALL-DLSSNR.md` to update the
   installed files while preserving your configuration, separately supplied NR runtime and other mods.
3. **Replace the DLL the game actually loads.** If OptiScaler was installed as `dxgi.dll`, for example,
   use this package's `OptiScaler.dll` to replace that OptiScaler-owned proxy. Merely adding an unused
   `OptiScaler.dll` beside an old proxy will not update the running mod. Do not overwrite a proxy
   owned by ReShade, another mod or the game.
4. Keep the package's backend directories and forwarder together. New features remain off by default;
   preserve/merge existing INI settings rather than blindly replacing a working configuration.
5. Enable **Apply before Super Resolution**, start with one NR pass and 100% model resolution, with
   FG/RR off. Switch DLSS modes and inspect `OptiScaler.log` for the active/target/model dimensions.

Non-zero colour offsets and invalid layouts still fall back after SR. RR still uses the separate
post-RR path. Frequent dynamic-resolution changes can cause model rebuilding overhead.

## Checks and limits

Release x64 DLL and forwarder built successfully. Headless D3D12 WARP tests verified every copied
pixel and preserved padding for 2558x1439, 2227x1253 and exact 1920x1080 inputs, including no-UAV and
simulated failure cases. Existing skin shader tests passed. The system D3D12 debug layer was unavailable.
Existing compiler/linker warnings remain. Dawnwalker, 1507x847 model evaluation and NVIDIA's acceptance
of these exact odd-sized model inputs still require in-game confirmation.

The release includes `SHA256SUMS.txt` for its contents. `ASSET-SHA256SUMS.txt` beside the download
contains the ZIP checksum. Verify your download and keep antivirus enabled.
